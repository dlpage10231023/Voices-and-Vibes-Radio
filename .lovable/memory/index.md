Voices & Vibes Radio design system, fonts, colors, and project constraints

## Colors (HSL in CSS vars)
- Background: #0a0a0a → hsl(0 0% 4%)
- Card: #1a1a1a → hsl(0 0% 10%)
- Footer: #060606
- Foreground: #f0f8f8 → hsl(180 33% 96%)
- Muted: #8ab8b8 → hsl(180 22% 64%)
- Primary (teal): #009B9B → hsl(180 100% 30%)
- Secondary (coral): #E8624A → hsl(12 72% 60%)

## Fonts
- Headings: Montserrat (font-montserrat) — black weight, uppercase
- Script/Accent: Dancing Script (font-dancing) — cursive highlights
- Italic subtitles: Playfair Display (font-playfair)
- Body: Montserrat light (font-montserrat)

## Constraints
- Dark backgrounds only, no light
- No stock photos unless provided
- No Lorem Ipsum — exact copy only
- framer-motion approved, no other UI libs
- Single-page scroll + routed day pages (/sunday..saturday)
- No border-radius (--radius: 0rem) — sharp edges throughout
- Teal/coral dual accent palette — NOT amber
